# LoCoMo data

The reproduction scripts expect the LoCoMo benchmark file at:

```
data/locomo/locomo10.json
```

It is **not redistributed here** — please download it from the official
release and place it at the path above:

- LoCoMo (Maharana et al., ACL 2024): https://github.com/snap-research/locomo
- Paper: arXiv:2402.17753

LongMemEval-S is loaded automatically from the Hugging Face Hub by
`lme_interaction.py` / `lme_maxsim.py` (no manual download needed).
